# UniLit Wallet Release Notes

## v1.0.1

UniLit Wallet 1.0.1 cleans up setup and stops Chrome from showing an Errors button on unpacked installs.

- Extension pages no longer point at the Chrome manifest as a web app manifest, so loading the extension unpacked does not raise a manifest warning.
- The home screen no longer shows the ordinals compatibility notice.
- Hardware wallet setup is removed from the welcome screen.
- Restoring a wallet now offers UniLit and other wallets only.

## v1.0

First release of UniLit Wallet.

This release ports UniSat wallets to UniLit.
